# 커버리지 검사 상세

사용자·프로젝트 기준을 우선한다. 목표가 없으면 비율과 중요한 누락 동작을 보고하고 임의의 100% 목표를 추가하지 않는다. 실제 기준 검사와 표시용 LCOV 계산을 구분한다.

## 제외 규칙

`**/*.{g,freezed,gen}.dart`와 실제 생성·지역화 경로를 검토한다. 도구가 중괄호 확장을 지원하는지 확인한다. 지원하지 않으면 동등한 필터를 사용하고 제외 범위를 설명한다. 가장 쉬운 글로브 하나만 쓰고 같은 기준을 적용했다고 주장하지 않는다.

## 계산

LCOV의 `SF`는 파일, `LF`는 대상 줄, `LH`는 실행된 줄, `DA`는 줄별 실행 횟수다. 전체 비율은 파일별 비율 평균이 아니라 `sum(LH) / sum(LF)`다. 분모가 0이거나 파일이 없으면 100%로 간주하지 않는다. 미커버 줄이 많은 파일부터 확인한다.

표시용 계산도 기준 검사와 동일한 파일·줄 제외를 적용한다. 테스트가 가져오지 않은 수작업 소스까지 수집되는지 확인한다. 관찰되지 않은 파일을 분모에서 누락해 거짓 100%를 만들지 않는다.

## ignore 주석

`check_ignore`와 `coverage:ignore` 처리 방식은 러너·Dart/Flutter 모드·버전에 따라 확인한다. 설정이 존재한다는 이유만으로 적용됐다고 가정하지 않는다. 생성 파일은 파일 제외로, 실제 도달 불가 줄은 근거와 프로젝트 정책에 따라 처리한다.

## LCOV 없음

| 원인 | 처리 |
| --- | --- |
| 커버리지 옵션 누락 | 호출을 수정해 재실행 |
| 테스트 성공했지만 파일 없음·모두 skip | 측정 불가로 보고, 설정·수집 확인 |
| 테스트 파일 자체가 없음 | 테스트를 작성하고 다시 검증 |

실행 전 파일 시각·해시를 기록하거나 해당 생성 산출물만 정리한다. 이번 테스트가 성공하고 새 LCOV가 생성된 경우에만 사용한다. 오래된 파일을 현재 결과처럼 읽지 않는다.
