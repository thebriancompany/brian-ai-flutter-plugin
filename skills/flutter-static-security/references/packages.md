# 관련 패키지

프로젝트 버전·플랫폼 지원과 유지보수 상태를 확인하고 선택한다. 표는 강제 설치 목록이 아니다.

| 패키지 | 용도 |
| --- | --- |
| `flutter_secure_storage` | 민감한 로컬 값의 플랫폼 보호 저장 |
| `http_certificate_pinning` | 위협 모델에 따른 인증서 고정 |
| `local_auth` | 생체 인증 |
| `crypto` | 표준 해시 등, 비밀번호 저장 해시와 구분 |
| `dart_crypt` | 기존 SHA-512-crypt 등 구현 참고 |
| `formz` | 타입이 있는 폼 검증 |
| `osv-scanner` | 해결된 의존성의 알려진 취약점 검색 |
| `freerasp` | 런타임 무결성 탐지 |

심각도는 [스킬의 기준](../SKILL.md)에 따라 Critical·Warning·Note로 보고한다.
